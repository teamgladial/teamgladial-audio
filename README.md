# Gladial Music

A creative home for music under the Gladial umbrella: releases, sketches, listening experiments, and notes from the process. The repository remains `teamgladial-audio`.

## Local development

```sh
npm install
npm run dev
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `>=22.12.0`

This is a static Astro site; no Cloudflare adapter or server runtime is required.
